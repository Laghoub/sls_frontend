Règles appliquées

  • Seuls les élèves avec une scolarisation active sont facturés.
  • Le périmètre cycle / niveau / classe / campus du tarif est respecté.
  • Les créances déjà générées sont automatiquement ignorées.
  • Les frais créés apparaissent ensuite dans les encaissements et la ventilation familiale.
