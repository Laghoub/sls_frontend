Fonctionnement automatique
Lorsqu'une nouvelle scolarisation est créée, le backend recherche les tarifs SCOLARITE applicables et génère les échéances correspondantes. Il n'est donc plus nécessaire de venir générer les mensualités élève par élève dans le fonctionnement normal.
